# Mochi 🍡🌱

The download page for **Mochi**, a tiny break-time friend for macOS.

👉 **https://anhlam09.github.io/mochi-site/**

Downloads live under [Releases](https://github.com/Anhlam09/mochi-site/releases). Each release lists the SHA-256 fingerprint of its zip, so you can check that your download is the real one.

This repository holds only the website: plain HTML, CSS and images, with no JavaScript, no trackers and nothing loaded from other sites.
