# Security

- Only download Mochi from https://anhlam09.github.io/mochi-site/ or this repo's Releases page.
- Check the SHA-256 fingerprint shown on the page before opening the app.
- Mochi never connects to the internet and collects no data.

Found a problem? Please report it privately with GitHub's **Report a vulnerability** button under this repository's **Security** tab, rather than in a public issue.
